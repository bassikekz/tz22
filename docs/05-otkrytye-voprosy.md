# Открытые вопросы к Заказчику по ТЗ П.22 v.2

Сводный реестр вопросов, выявленных при разборе ТЗ и проектировании архитектуры
(приложения `arch/01`…`arch/06`). Вопрос попадает в реестр, если ТЗ требует
функцию или норматив, но не даёт данных, достаточных для реализации либо для
проверки на приёмке.

Приоритет: **Б** — блокирует разработку соответствующего модуля; **П** —
требуется до Программы и методики испытаний либо до приёмки; **С** — уточняется
в ходе обследования без остановки работ.

## 8. Порядок закрытия

1. Вопросы приоритета **Б** закрываются до начала разработки соответствующего
   модуля; для этапа 2 критичны разделы 1, 2 и 5 настоящего реестра.
2. Вопросы приоритета **П** фиксируются в Программе и методике испытаний
   (P22-38) либо в согласованных эксплуатационных документах — без этого
   соответствующий норматив непроверяем на приёмке.
3. Вопросы приоритета **С** закрываются отчётом предпроектного обследования
   (P22-15) и не останавливают работы.
4. Выявление в ходе обследования особенностей инфраструктуры, которые могли быть
   определены при надлежащем обследовании, не является основанием для исключения
   предусмотренной ТЗ функциональности (раздел 17 общего ТЗ).
