# ТЗ П.22 — платформа киберучений и устойчивости работников (CA PS)

Репозиторий ведения технического задания П.22 и его сопоставления с проектом
**P22 «Киберучения и устойчивость работников (П.22)»** в YouTrack
(https://bassikekz.youtrack.cloud/projects/P22).

Работа выполнена по той же схеме, что и для П.17 (проект `P17`, репозиторий `tz17`):
месячное ТЗ раскладывается в веху и задания, общее ТЗ сопоставляется с бэклогом,
непокрытые требования добавляются как задания с пометкой «Пробел покрытия».

## Исходные документы

| Документ | Содержание |
|---|---|
| `ТЗ CA PS на октябрь 2026` (CA_PS-2026-10) | месячный объём: компонент публикации учебного материала и компонент назначения и учёта прохождения |
| `Общее ТЗ П.22 v.2` | полный объём платформы: разделы 1–24 |

## Состав

- `docs/01-analiz-tz-ca_ps-2026-10.md` — разбор месячного ТЗ и состав работ.
- `docs/02-sopostavlenie-s-youtrack.md` — сопоставление общего ТЗ с бэклогом P22, перечень пробелов покрытия и созданных задач.
- `docs/03-arhitektura-i-razvertyvanie.md` — решение по способу развёртывания (монолит или микросервисы) и схема компонентов.
- `.claude/agents/` — ролевые агенты по составу команды проекта (поле «Роль» в YouTrack).
