## Правила работы над задачей

1. Перед реализацией прочитать постановку задачи в `docs/postanovki/` и пункт ТЗ,
   на который она ссылается. Если постановки нет — сначала постановка.
2. Один диф — одна задача бэклога; номер задачи указывается в сообщении коммита.
3. Требование без основания в ТЗ не реализуется: либо ссылка на пункт, либо
   пометка «предложение Исполнителя» и согласование.
4. Значение, не заданное ТЗ (порог, вес, интервал, формат), не выдумывается —
   ставится ссылка на номер вопроса из `docs/05-otkrytye-voprosy.md`.
5. Негативные проверки Н-1…Н-12 из `docs/postanovki/00-shablon-i-pravila.md`
   применяются к каждой задаче, где применимы; человек выполняет их вручную
   хотя бы один раз, не доверяя только автотесту.
6. Проверка полномочий — всегда на стороне приложения; интерфейс только скрывает
   недоступное. Для каждого запрета интерфейса нужен отказ сервера при прямом
   вызове API.
7. Секреты не попадают в код, образы, журналы, отчёты и выгрузки. Значение
   введённого в учебном сценарии секрета не сохраняется нигде.
8. Каждая прикладная операция и каждый отказ в доступе попадают в журнал:
   пользователь, время, объект, операция, результат.
9. Код, который человек не прочитал, в поставку не идёт.

## Чего Claude не делает без человека

Согласование объёма и сроков с Заказчиком, подписание актов и протоколов,
решения о составе собираемых персональных данных и сроках хранения, выбор
классификации дефектов, допуск версии к передаче, изменение методик оценки.

## Работа с YouTrack

- Значения поля `Type` передаются по-английски: `Task` (отображается «Задание»),
  `Epic` («Веха»); русские значения API отклоняет.
- Поля задачи: `Этап`, `Тип работы`, `Роль`, `Дата начала`, `Due Date`. Поле
  «Роль» означает функцию, а не исполнителя.
- В описании задачи первая строка — `Основание: <документ>, п. <номер>`.
- Теги создаются только администратором проекта; распределение по исполнителям
  держится в `docs/07-komanda-i-raspredelenie.md`.
- Задачи по пробелам покрытия ТЗ помечаются в описании `**Пробел покрытия:**`.
